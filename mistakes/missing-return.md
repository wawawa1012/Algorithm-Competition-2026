# 缺失函数返回值

**出现次数：4**（按 AGENTS.md 此前累计 3 次，加 2026-10-27 本次）。本文件已列明的记录包括 2026-09-25 `searchRange`、`two_sum` 及本次 `same_color_ordered_pair`；旧累计中的另一笔未在此补造题名。

## 症状

- 编译警告：`no return statement in function returning non-void` / `control reaches end of non-void function`
- 运行时：崩溃（如 exit code `0xC000001D`）或输出乱码/垃圾值

## 原因

非 void 函数存在"执行到函数末尾却没有 return"的路径（通常在所有循环结束之后）。

## 防御习惯

1. 写完函数先自问：**所有路径都有 return 吗？** 尤其是循环全部走完的那条路
2. 函数末尾返回题意约定的结果或明确的无解标记；不能为了消除警告随意返回 0，因为 0 可能是合法答案。
3. 编译必须**零警告**再运行，警告就是免费的错误提示

## 2026-10-27 同色有序配对

- 函数只有 `if (m != -2000000001) return m;`，无合法配对时执行到末尾而未返回。
- 最短触发条件是 n=1；应按约定返回无解标记，再由 main 输出 IMPOSSIBLE。
- 本题负分也可能是合法最优分数，不能用负数或 0 笼统代表无解；空标记必须位于合法范围之外。
- 修正：学员已自行补齐末尾 return 和 main 无解分支，教练应要求修正最后两处常量/变量同步错误；16 组定向及 50 组穷举随机对拍通过。该次缺返回已处理，不重复计数。
