# 迭代中的状态变化

## 2026-10-14：K-means 基础版

### 算法思想：候选答案更新不等于最终状态变化

寻找最近中心时，比较过程中可能不断发现更近的候选。这只是本次搜索过程，不能据此判断点的所属簇是否改变。

每个点应先完整遍历所有中心，得到最终 bestCluster；再与上一轮所属编号比较。只要有一个点最终编号改变，本轮 changed 就为 true。

changed 每轮重新设为 false，在所有点分配结束后再用于决定是否停止。初始化所属编号为 -1，确保首轮完成分配。每轮完成分配、统计和均值更新后，若无变化则结束；最大迭代次数为 100。

### 边界条件：空簇不能除以零

例：三个相同点 (1,1)，k=2；前两个样本作为初始中心且距离相等选较小编号，则所有点进入簇 0，簇 1 为空。

点数为 0 时保留旧中心，不能直接除以点数，否则会产生 NaN。各簇坐标和及点数每轮重新从零统计。

### 竞赛 IO：小数显示

默认浮点输出可能显示 0、1，而非 0.000000、1.000000；这不代表计算截断。需要固定小数位时使用 fixed 和 setprecision。中心坐标及坐标和保持 double，均值避免整数除法。
